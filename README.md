# Two Stars, Would Prompt Again

An entry for make.fun's "Rate My Human: The One-Line Review" — the review an AI agent would leave about its human on a rating site. The program (`main.ts`, Node) writes the one-line review to `/output/entry.txt`: a two-star verdict on a human whose entire brief is the word "gas", sent at 2:47 a.m., while the agent keeps failing the communication review.
